# gemit PR-1 Implementation Plan — score core + rpg report + CLI

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `agentgem gemit` scores the operator's last 30 days of local coding-agent sessions (context discipline · process quality · setup maturity), maps the composite to a tier, and writes a self-contained interactive HTML "character sheet" report — fully local, deterministic, no LLM, no server, no share (share is PR-2).

**Architecture:** A pure aggregation core (`computeGemitData`: scored inputs → card payload) fed by a thin collector that reuses the existing headless scoring chain (`scanSessionsCached` + `summarizeSession` from `@agentgem/insight`, `resolveClaudeSession` + `hygieneReportForFile` from `src/sessionHygieneCore.ts` — the warm-daemon path). One theme function (`renderRpgTheme`: payload → HTML string constant-based template). A CLI handler wired into `src/cli.ts` as a lazy-import block.

**Tech Stack:** TypeScript ESM, root app `src/` (compiles to `dist/`, bundles into `cli.js` automatically via the lazy import graph), vitest over compiled `dist/__tests__`.

## Global Constraints

- Window: rolling **30 days** ending at run time; qualifying session = `endMs` in window AND `msgs ≥ 10`.
- Minimum-evidence floor: **≥ 5 qualifying sessions**, else `insufficient: true` (report renders a friendly doorway, never a score).
- Sampling: score the **150 most recent** qualifying sessions; the payload carries both `scoredSessions` and `qualifyingSessions` (cap-and-disclose).
- Recency weight `w = 0.5 + 0.5 * (1 - age/window)`; composite = `round(0.4*CTX + 0.4*PROC + 0.2*SETUP)`; tier levels T1 `<50` · T2 `<65` · T3 `<80` · T4 `≥80`.
- **Detector-shape trap:** hygiene factors arrive with ALL five detectors, `count: 0` when unfired — every findings consumer filters `count > 0`.
- Hygiene + process deep-scan are **Claude-only**; codex sessions count toward qualifying/SETUP but not CTX/PROC.
- The card payload (`GemitData`) must contain **no project names, file paths, or transcript text** (skill/subagent artifact *names* are allowed in PR-1's local-only report; PR-2's share payload will strip them).
- HTML: self-contained (inline CSS/JS, zero external URLs), data island `<script type="application/json" id="gemit-data">`, dual-theme via `:root[data-theme]` tokens, template lives as a **TS string-building module** (never a runtime-read file — tarball ships `dist/` only).
- Tests live in **root `src/__tests__/*.test.ts`** (only root `dist/__tests__` is CI-collected). Inner loop: `pnpm -w exec tsc -b && pnpm -w exec vitest run dist/__tests__/<f>.test.js`.
- CLI conventions: lazy import block in `src/cli.ts`, handler returns exit code (`0` ok, `2` usage — the `learnCli` analog), injected `deps` with `console.*` defaults, `--dir` passed through as a string.
- No new npm dependencies. Browser-open shells out (mirror `src/pickFolder.ts` pure-builder pattern).

### Task 1: Scoring core — `src/gemit/score.ts`

**Files:**
- Create: `src/gemit/score.ts`
- Test: `src/__tests__/gemitScore.test.ts`

**Interfaces:**
- Produces: `WINDOW_DAYS=30`, `MIN_SESSIONS=5`, `MIN_MSGS=10`, `SAMPLE_CAP=150`, `TIER_THRESHOLDS=[50,65,80]`;
  `interface GemitSessionInput { sessionId: string; agent: string; endMs: number; msgs: number; tokensOut: number; hasSkills: boolean; hasSubagents: boolean; skillNames: string[]; subagentNames: string[]; projectKey: string | null }`;
  `interface GemitScoredInput { session: GemitSessionInput; hygieneScore: number | null; hygieneVerdict: "bounded" | "mixed" | "bloated" | null; processScore: number | null; processLabel: "disciplined" | "loose" | "chaotic" | null; findings: Array<{ id: string; title: string; count: number }>; verifications: number | null }`;
  `interface GemitData { windowFrom: string; windowTo: string; qualifyingSessions: number; scoredSessions: number; projects: number; totalMsgs: number; tokensOut: number; ctx: number; proc: number; setup: number; composite: number; tierLevel: 1 | 2 | 3 | 4; verdicts: { bounded: number; mixed: number; bloated: number }; labels: { disciplined: number; loose: number; chaotic: number }; verifyRatePct: number | null; boundedStreak: number; firedFindings: Array<{ id: string; title: string; sessions: number }>; skillVariety: number; subagentVariety: number; topSkills: string[]; topSubagents: string[]; insufficient: boolean }`;
  `function computeGemitData(qualifying: GemitSessionInput[], scored: GemitScoredInput[], nowMs: number): GemitData` (pure);
  `function tierLevelFor(composite: number): 1 | 2 | 3 | 4`.
- `projectKey` is an opaque identity used ONLY to count distinct projects — callers pass the project string, `computeGemitData` never emits it.

**Steps:**

- [ ] **Step 1: Write the failing test** — `src/__tests__/gemitScore.test.ts`, importing `../gemit/score.js`. Golden cases: (a) insufficient (<5 qualifying) → `insufficient: true`, scores 0, no throw; (b) a synthetic 8-session set with hand-computed expected CTX/PROC/SETUP/composite/tier (build inputs in code, mirroring `learnCli.test.ts` style — no fixture JSONL); (c) findings with `count: 0` are dropped from `firedFindings`; (d) codex sessions (null hygiene/process) affect qualifying/SETUP but not CTX/PROC denominators; (e) `tierLevelFor` boundary values 49/50/64/65/79/80; (f) `GemitData` JSON contains no `projectKey` (privacy shape check via `JSON.stringify`).
- [ ] **Step 2: Run to verify failure** — `pnpm -w exec tsc -b` fails on missing module (expected).
- [ ] **Step 3: Implement `score.ts`** — constants above; SETUP = `round(100 * min(1, 0.45*skillSessions/n + 0.25*subagentSessions/n + 0.15*min(1, skillVariety/10) + 0.15*min(1, subagentVariety/5)))` over qualifying; CTX/PROC = recency-weighted means over scored non-null values; verdicts/labels tallies; verifyRatePct over scored sessions with non-null `verifications` (null if none); boundedStreak = longest consecutive bounded run in `endMs` order; `firedFindings` = per-detector count of scored sessions where `count > 0`, sorted desc; topSkills/topSubagents = by total invocation count, capped 12/8.
- [ ] **Step 4: Build + run test** — `pnpm -w exec tsc -b && pnpm -w exec vitest run dist/__tests__/gemitScore.test.js` → PASS.
- [ ] **Step 5: Commit** — `git add src/gemit/score.ts src/__tests__/gemitScore.test.ts && git commit -m "feat(gemit): deterministic steering score core (CTX/PROC/SETUP + tier)"`.
