Miniapp MCP Connectors — Architecture

Sealed miniapps call the viewer's MCP server gems — consent-gated, host-brokered, manifest-enforced

Trust boundaries

  • • Sealed frame: sandbox=allow-scripts, zero network egress — data only via host bridge
  • • Consent per gem × server, remembered; never auto-granted
  • • Manifest enforced server-side: (server, tool) ∈ saved mcpNeeds
  • • Hosted marketplace play: mcp member absent → degraded, like public artifacts

Call path

  • • ① shim call → ② consent gate → ③ REST → ④ manifest check → ⑤ gem connect → ⑥ upstream
  • • Envelope mirrors window.claude.mcp: result.payload + coded errors
  • • watchTool: host-side poll registry (≥30 s), replay + cache.storedAt
  • • Errors: server_not_connected · server_unavailable · not_in_manifest · tool_error

Data & derivation

  • • GameArtifact.mcpNeeds: [{ server, tools[] }] beside needs
  • • Save-time deriveNeeds() MCP pass — literal server/tool strings only
  • • Declared-but-unused pruned → prunedMcpNeeds in save result
  • • Connector registry = installed mcp_server gems (McpServerArtifact)
