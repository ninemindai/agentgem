The context window is a bill you re-pay every turn.

Four real AgentGem work sessions, measured straight from the transcript — no model in the loop. Every assistant turn carries its own usage accounting, so the context curve is ground truth. Long isn't the smell. Unbounded task-mixing is — and it shows up as area under the curve.

How you'd actually detect this — two tiers

This maps straight onto the existing DetectorSpec.cost: "cheap" | "llm" seam in packages/insight. Cheap runs always, for zero tokens. The LLM is a confirmer, not a scanner — invoked only when cheap signals cross a threshold.
